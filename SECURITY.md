# Security policy

Please report suspected vulnerabilities privately to [support@modellix.ai](mailto:support@modellix.ai). Do not open a public issue containing API keys, credentials, request payloads, signed result URLs, or private local paths.

Include the affected CLI version, operating system, Node.js version, reproduction steps, and impact. Use a new test credential when possible and revoke it after testing. Modellix will acknowledge the report and coordinate disclosure after a fix is available.

Only the latest released version is supported with security fixes. For account or data-privacy requests, see the [Modellix Privacy Policy](https://www.modellix.ai/privacy).
